One painfully honest out-of-office auto-reply: a single sentence, at most 200 characters, honest about the sender's absence and inbox, yet polite enough that a manager would let it stand.

Run with `MAKEFUN_OUTPUT_DIR` set; `main.ts` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
